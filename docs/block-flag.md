# block-flag — تفکیک بلاک میزبان از رزرو واقعی

**مسئله:** در `jajiga-tracker/data/radar/history/radar_history.db` ردیف‌های
`status='booked'` برای اتاق خودمان (3297585) شامل «بستن تقویم توسط میزبان» هم
هست — رزرو واقعی نیست. (کشف 2026-09-07: ۲۹ شب متوالی «پر» ولی درآمد واقعی فقط ۱ شب.)

**قانون موتور:** در محاسبه pace و backtest اتاق خودمان همیشه exclude می‌شود
(`room_id != 3297585`). رزروهای واقعی از `data/own_bookings.json` می‌آیند
(خروجی دستی از داشبورد رزروها).

**آینده:** اگر fetch_radar بتواند فیلد «بلاک» را از API جدا کند، این doc حذف می‌شود.
